Telepsych

Telepsych is a Django-based web application designed to support telepsychiatry and remote mental health services. It provides user account management, session handling, chat functionality, and integration points for telepractice workflows.

🧠 Overview

Telepsych is a Python web application built with Django to facilitate remote psychological consultations and virtual sessions. It includes:

User Authentication & Profiles — Sign-up/sign-in, role management

Session Scheduling & Tracking — Manage telepsych sessions

Messaging & Chat Support — Real-time communication via stored chat files/folders

Template-based UI — Django HTML templates for front-end views

The app is suited for telehealth providers, therapists, and developers building customizable remote care platforms.

🚀 Features

✔ User registration, login, and profile management
✔ Session creation and management
✔ Messaging/chat functionality between users
✔ Backend models for sessions and users
✔ Designed for deployment on AWS or similar hosting
